# Qwen3-0.6B LoRA comparison: run summary

The full three-epoch LoRA run and paired first-pass evaluation completed on a Tesla T4 in Colab. The adapter weights and raw paired outputs remain in the team's Google Drive; only compact metadata and summary metrics are stored in this repository.

## Training

- Base model: `Qwen/Qwen3-0.6B`, revision `c1899de289a04d12100db370d81485cdf75e47ca`.
- Data: 2,822 train examples from 208 tasks; 599 development examples from 46 tasks.
- Configuration: 3 epochs; learning rate 1e-4; effective batch size 16 (micro-batch 1, accumulation 16); FP16; gradient checkpointing; LoRA rank 8, alpha 16, dropout 0.05.
- Runtime: Tesla T4; 4,954 seconds including final evaluation (about 82.6 minutes); train loss 0.0663; final dev loss 0.0692.
- A CUDA allocator warning appeared during training, but the run continued through all 531 steps and completed. See `training/training_metadata.json` for recorded versions and run details.

## Paired evaluation

Both models were generated on the same 618 held-out examples across 41 task clusters, with shared prompts, levels, generation parameters, and per-example seeds.

| Metric | Base Qwen | LoRA Qwen |
|---|---:|---:|
| Rule-validator acceptance | 99.19% | 99.51% |
| Rule-validator compliance | 99.35% | 99.51% |
| Rule-validator leakage flags | 0.16% (1/618) | 0.00% (0/618) |
| Mean generation latency | 1.53 s | 2.62 s |

The paired acceptance difference was +0.32 percentage points (task-cluster bootstrap 95% interval: -0.73 to +1.27 points). The interval includes zero, so this run does not establish an acceptance improvement. LoRA generation was about 72% slower on average. The overall validator rates are near ceiling, and this rule-based validator does not measure relevance, factual correctness, or usefulness.

Coding acceptance was 98.51% for base and 98.88% for LoRA (n=268); science acceptance was 99.71% and 100.00% (n=350). By level, acceptance was 100% for both at L1 and L3; at L2 it was 97.42% vs 98.06% (n=155), and at L4 it was 99.35% vs 100% (n=153).

## Limits and remaining P4 item

Training targets were filtered hints from the existing bank, predominantly generated by the same base model. This is self-distillation; it is not human-corrected supervision. The experiment only supports a comparison on rule-validator outcomes and generation latency. It says nothing about learning gains or real learners.

Human relevance, correctness, and level-fit ratings remain pending. The blinded rating sheet is in Drive; add those results only after actual raters complete it. The result JSON here was transcribed from the Colab output supplied by the team member; raw outputs and the adapter were not available in this local checkout.
